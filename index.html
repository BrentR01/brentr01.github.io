Personal backup utility

SkyWatch Backup

A private, owner-operated backup utility for a home aircraft-tracking project and its PlaneDex aircraft-card collection.

Informational site only

What the application does

When the owner enables it, SkyWatch Backup runs on the owner's Raspberry Pi and creates recovery archives containing the SkyWatch and PlaneDex application files, local collection databases, settings, and user-selected aircraft photographs.

It uses rclone and the Google Drive API to upload these archives and verify that the uploaded copies can be retrieved intact. The Google account used for this purpose is a dedicated, owner-controlled backup account.

Why Google Drive access is requested

Google Drive access is needed solely to create, list, retrieve, verify, and, when explicitly configured, manage the owner's backup files. The application is configured to request the drive.file scope, which limits access to files created or opened by the application rather than unrestricted access to all Drive content.

This is a personal single-user utility, not a public cloud-storage or file-sharing service. This informational website does not log into Google, run backup jobs, provide remote access to the Raspberry Pi, or collect visitor information.

Personal-use terms

The software is maintained for the owner's personal home project, provided as-is without commercial service commitments. Backups must be tested before reliance on them; they are not a substitute for independent recovery copies.
